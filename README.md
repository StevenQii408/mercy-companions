# 仁慈之剑 · Mercy Companions

Minecraft **26.3 / Fabric** 的 **0.4.2**。用低伤害的仁慈之剑完成最后一击，将原版敌对生物收入伙伴收纳袋，再对地面右键召唤。末影龙除外。

## 安装

[下载 0.4.2 Beta 模组 JAR](https://github.com/StevenQii408/mercy-companions/raw/refs/heads/main/dist/0.4.2/mercy-companions-0.4.2%2B26.3.jar) · [SHA-256 校验文件](dist/0.4.2/SHA256SUMS.txt)

- Minecraft Java Edition **26.3**
- Fabric Loader **0.20.1 或更高**
- 适用于 26.3 的 Fabric API **0.166.2 或更高**
- Java **25 或更高**

将本项目发布的 `mercy-companions-0.4.2+26.3.jar` 和对应版本的 Fabric API 放入游戏实例的 `mods` 文件夹，然后重新启动游戏。多人游戏的服务器和每个客户端均需安装。本模组没有 Forge 或 NeoForge 版本。

## 开始游玩

每位玩家在每个世界首次加入时会获得仁慈之剑和伙伴收纳袋；旧版玩家升级后首次进入会补发袋子。允许先用其他武器削减目标血量，再用仁慈之剑直接击中目标完成收服。

1. 用仁慈之剑完成可收服生物的最后一击，伙伴会回满血并进入袋中。
2. 手持袋子，对有足够空间的地面顶面右键召唤。
3. 在物品栏把鼠标停在袋格上，用滚轮浏览，再右键袋格收回伙伴或调整下一位出战伙伴。

伙伴不自动回血，死亡后永久失去；收回需要脱战至少 10 秒。详细规则如下。

- **收服入袋**：收服成功后直接存入袋中，默认后进先出。袋内顺序由服务器保存。
- **召唤**：手持伙伴收纳袋，对地面顶面右键，一次召出下一位伙伴。冰面、积雪、半砖、地毯和树叶均按实际可站立的高度放置伙伴。目标位置必须有足够空间；失败不会弹出栈内记录。
- **浏览**：鼠标停在袋格时，用滚轮切换查看伙伴的名字和血量。高亮表示正在查看的伙伴，▶ 表示下一位出战伙伴。右键确认前，滚轮浏览和移开鼠标都不会改变出战顺序。
- **袋子右键**：把鼠标停在袋子所在的物品格，用滚轮切换伙伴，再右键袋子。已出战的伙伴会远程收回并放到栈顶，未出战的伙伴直接移到栈顶。鼠标一离开袋格，头像预览立即收起。右键不会拿起袋子，左键仍可移动袋子；鼠标已拿着物品时保留原版物品操作。
- **收回**：也保留手持袋子右键自己伙伴的近距离操作。远程回收支持走远、跨维度或区块已卸载的伙伴，不需要前往其位置，仍受脱战冷却限制。已出战伙伴不能通过袋子再召一份。
- **查看**：悬停袋子显示原版收纳袋风格的像素格子和伙伴头像，正常格子数随契约等级从 3 增加到 7；滚轮选中的伙伴显示名字、生命数值和血条。上箭头表示已出战，小锁表示超出当前容量的封存伙伴。封存区单独展示，避免丢失原有伙伴信息。旧管理页面已移除，伙伴默认跟随有效的主人。
- 仁慈之剑与伙伴收纳袋使用原版史诗稀有度的紫色物品名。
- 已出战伙伴周围会交替出现蓝色、白色的原版药水螺旋粒子（每位伙伴每秒约 5 枚，32 格内可见），仅主人客户端可见；不会给野怪或其他玩家的伙伴加标记，遵循原版粒子设置。
- 默认拥有 3 个名额；在附魔台取得 **契约 I–IV**，每级增加一个名额，最多 7 个。收纳中的伙伴也占名额，多把剑不会叠加名额。
- 容量取背包内仁慈之剑的最高契约等级；没有附魔剑时是 3。移走剑或降低等级不会收回已出战伙伴，只会暂时锁定袋内超出容量的槽位。
- 伙伴属于玩家和世界；多个袋子查看同一个名册，不会复制伙伴或叠加容量，交给别人也不会转移伙伴所有权。
- 剑遗失后，可用 **木剑 + 线 + 青金石** 无序合成。仁慈之剑的基础攻击力与木剑相同，不消耗耐久。
- 袋子遗失后，可用 **皮革 + 线 + 青金石** 无序合成，已拥有的伙伴不会因袋子遗失而消失。
- 创造/测试命令：`/give @s mercy_companions:mercy_sword`、`/give @s mercy_companions:companion_bag`；手持剑执行 `/enchant @s mercy_companions:covenant 4`。

## 战斗和生命规则

收服会取消死亡，不产生击杀经验或掉落；首次收服回满血、移除原有状态效果。仁慈之剑的直接伤害不会杀死生物：可收服的主目标按原规则收服，满员、不能收服的敌对生物、友好/中立生物、现有伙伴及横扫副目标都保留 1 点生命。横扫副目标不会被收服，末影龙仍不能收服。其他武器、环境伤害和后续燃烧仍可致死；该保护不适用于玩家和盔甲架。

锁敌分为两类：

- **协助主人**：僵尸、骷髅、苦力帕等只锁定主人攻击过的目标，或伤害主人的目标；仅仅受到其他生物攻击，不会自行扩大攻击对象。
- **保留原生主动索敌**：监守者、凋灵、僵尸疣猪兽以及命名为 Johnny 的卫道士等原本广泛攻击第三方生物的种类，仍会主动寻找原版认可的敌人，保留物种自身的目标偏好。

两类都排除主人和同一主人的其他伙伴。它们仍可能通过范围攻击造成误伤。

攻击动作沿用原版，不为生物额外增加近战：苦力帕靠近后自爆，僵尸近战，持弓骷髅射箭。也保留原版条件分支，例如骷髅失去弓后近战、烈焰人近距离近战而远距离发射火球、溺尸持三叉戟时投掷、猪灵依据武器切换。巨人原版没有攻击 AI，本模组不额外赋予攻击；无攻击能力的功能生物收到主人战斗事件后仍可正常跟随。

| 伤害来源 | 主人是否受伤 |
| --- | --- |
| 伙伴近战、普通箭矢、监守者音爆等直接攻击 | 否 |
| 苦力帕爆炸、烈焰人火球与燃烧、恶魂火球、凋灵之首爆炸 | 是 |
| 药水、药水云等范围魔法伤害与负面效果 | 是 |

主人能伤害伙伴，伙伴之间也会误伤，但不会因此互相报复。伙伴的爆炸与弹射物不破坏地形；火球直接命中仍能点燃生物。监守者的黑暗效果保留。

伙伴不自动回血，凋灵的被动/击杀恢复和女巫自行制造的治疗药水已禁用。玩家可以手动使用药水等治疗；仍遵循原版亡灵反转规则，例如僵尸应使用伤害药水治疗，治疗药水反而会伤害它。

生命归零即永久死亡，释放名额，无法复活；伙伴死亡也不产出经验或战利品。苦力帕主动自爆会消耗这个伙伴。召回和再次召唤保留生命值及状态，不会回满血。

主动收回需要距上次造成或受到伤害至少 10 秒；再次召唤有 2 秒冷却。**只有主动收回才重新入袋**：退出游戏、主人死亡、跨维度、移走武器、降低容量或区块卸载，都不会自动收纳。主人不在同一世界或离线时停止跟随；伙伴留在所在世界。区块再次加载或重启后，会在记录的位置和维度恢复，保留生命、身份和出战状态。和平难度也不会让已收服伙伴自然消失，但正常受伤死亡仍永久失去。

## 特殊生物处理

范围为 **26.3 原版注册的 MONSTER 类别生物，加上明确支持的末影人和杀手兔变种，排除末影龙**。保留各自原生攻击类型和环境弱点，例如亡灵日晒、水中/陆地差异、火焰抗性。僵尸鹦鹉螺等水生伙伴需要适合的水环境，收服不会取消原生环境伤害。其他 Mod 的自定义 AI 不在本版兼容承诺内。

- 监守者：维持针对敌人的怒气与攻击，收服后不钻地消失。
- 凋灵：取消收服后的生成蓄力爆炸、自动回血和无目标轰炸，保留战斗发射物。
- 嘎枝：仁慈之剑可对与苍白之心绑定的嘎枝完成收服；收服后解除双方连接，不再受注视停步和苍白之心销毁控制。
- 唤魔者：保留尖牙和原版恼鬼召唤。其召唤的恼鬼是临时随从，不占永久伙伴名额，也不能被仁慈之剑收服或放入袋中；遵循主人的友方保护与目标规则，唤魔者被收回、死亡或离开已加载世界时一并消失。野生恼鬼仍可独立收服。
- 潜影贝：保留弹射物与传送，增加附着点跟随传送，禁止复制产生额外伙伴。
- 史莱姆/岩浆怪等方块生物：适配跳跃跟随与攻击，伙伴死亡不分裂。
- 蠹虫：禁止钻入石头消失、唤醒其他蠹虫。
- 僵尸：禁止召唤增援；正常实体转化会迁移伙伴记录和剩余生命，保留一个名额。
- 恶魂、幻翼、恼鬼、凋灵：采用飞行跟随；保留原版攻击方式。
- 僵尸马、骆驼尸壳：保留原版坐骑功能，屏蔽原版马类随机回血；不额外赋予原本不存在的近战攻击。
- 硫方怪：保留原版容纳方块的功能与原生不攻击的特点；伙伴不能装入桶，避免名册和实体桶重复保存。取出方块后恢复跟随。
- 杀手兔：支持命令生成的敌对兔变种，按协助主人的方式战斗；普通兔不属于收服范围。
- 骑乘组合：只收服被剑直接击中的个体，同时拆开坐骑与骑手；其他个体仍需单独收服。

## 世界数据

伙伴数据保存在世界目录 `data/mercy_companions.json`，同时记录袋内栈顺序和已出战伙伴的世界位置。它是伙伴的唯一持久化来源，同一伙伴不会再写入原版实体区块文件。加载出战伙伴前会检查 UUID，避免重复实体；恢复不依赖主人上线，也不会把它移到主人所在维度。旧版数据迁移前保存 `mercy_companions.v1.backup.json`，旧版已收纳伙伴进入袋内栈。备份或迁移时应保留整个世界目录。文件格式异常时保留原文件并停止新增收服、召唤。

## 兼容与显示

可搭配兼容 Minecraft 26.3 / Fabric 的其他模组。本模组的兼容承诺覆盖上述原版生物；其他模组生物的自定义 AI，以及会收纳、复制或替换实体的功能，需要单独验证。

伙伴收纳袋使用原版 Tooltip 流程，可在“选项 → 视频设置 → 界面尺寸”中调整显示大小。若血量、快捷栏和准星同时消失，可按 **F1**（Mac 可能需要 **Fn + F1**）切换 HUD 显示；隐藏 HUD 不代表人物死亡。

## 构建与验证

源码提供基于本地游戏依赖的 Python 构建脚本，不包含 Minecraft、Fabric API 或其他模组的二进制文件，也不会自动下载这些依赖。构建需要 Python 3 和完整 JDK 25+。

可通过以下环境变量指定已有依赖：

| 环境变量 | 内容 |
| --- | --- |
| `MERCY_LIBRARIES` | 游戏依赖目录，例如 Prism Launcher 数据目录中的 `libraries`，其中需要有 26.3 游戏 JAR、Fabric Loader 及其依赖 |
| `MERCY_FABRIC_API` | 适用于 26.3 的 Fabric API JAR 文件 |
| `MERCY_JDK` | 完整 JDK 25+ 的根目录；也可使用标准 `JAVA_HOME` |

构建脚本同时支持原开发工作区的 Prism 目录布局：项目与 `PrismData`、`downloads` 目录并列。其他目录布局请设置上述变量。

```sh
python3 scripts/build.py
```

输出为 `build/libs/mercy-companions-0.4.2+26.3.jar`。

以下集成测试和客户端预览脚本使用本地开发工作区，部分脚本还依赖 Prism 的资源目录、测试存档或已安装的附加模组。它们不是通用启动器；独立克隆源码后，需先准备相应路径及测试环境。

```sh
python3 scripts/run-tests.py
python3 scripts/run-ui-tests.py --bag-only --with-addons
python3 scripts/run-client.py
```

客户端预览脚本可通过 `MERCY_JAVA_HOME` 指定 Java 25+ 运行环境。`scripts/addons.py` 和 `scripts/run-xaero-smoke.py` 用于原开发工作区的附加模组诊断，需要本地实例和对应测试文件。

测试使用独立的 `build/test-server` 和 `build/test-client`，不读取登录账号或已有正式存档。测试服务器仅监听本机随机端口。服务器测试覆盖收服、伤害规则、容量附魔、死亡与持久化，以及逐种原版敌对生物的收服/召回/召唤。具体结果见 `TESTING.md`。
